# Velo Scoop bucket

```powershell
scoop bucket add adoxcol https://github.com/Adoxcol/scoop-bucket
scoop install veloctl
```

`veloctl` is the command-line downloader from [Velo](https://velo.adoxcol.com). For the full Velo app with browser integration, use the installer from the website or `winget install Adoxcol.Velo`.

The manifest is updated automatically by [Velo's release workflow](https://github.com/Adoxcol/velo).
